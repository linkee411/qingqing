# 青钱 · 记账（PWA）

一个只给你自己用的记账 App。手机浏览器打开、「添加到主屏幕」，用起来和装了个 App 一样。
数据全部存在你自己的设备上（localStorage），不上传任何服务器。

## 目录

```
qingqian-pwa/
├── index.html            整个 App（HTML + CSS + JS 全在一个文件里，无外部依赖）
├── manifest.webmanifest  应用信息：名字、图标、独立窗口打开
├── sw.js                 Service Worker：断网也能打开，导航请求走 network-first
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png
└── apple-touch-icon.png
```

## 怎么打开

**方式一：直接双击 `index.html`**（最简单，先用起来）
浏览器直接打开就能记账，数据存在本机。缺点：`file://` 下浏览器不允许注册 Service Worker，
所以不能「添加到主屏幕」，也不能离线。

**方式二：放到一个网址上（推荐，才能装到桌面）**

三种都免费、都不用命令行：

1. **Netlify Drop** —— 打开 https://app.netlify.com/drop ，把整个 `qingqian-pwa` 文件夹拖进去，
   几秒后给你一个 `https://xxx.netlify.app` 网址。手机上打开这个网址即可安装。
2. **GitHub Pages** —— 新建仓库，把文件夹里的文件传上去，Settings → Pages 选 main 分支，
   得到 `https://用户名.github.io/仓库名/`。
3. **Cloudflare Pages** —— 注册后 Upload assets，拖文件夹，得到 `https://xxx.pages.dev`。

要「添加到主屏幕」，网址必须是 **https**（上面三种自带）或 `localhost`。

**本机临时预览**（需要命令行）：

```bash
cd qingqian-pwa
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 添加到主屏幕

- **iPhone / iPad**：Safari 打开网址 → 分享按钮 → 「添加到主屏幕」。
- **Android**：Chrome 打开网址 → 右上角 ⋮ → 「安装应用」/「添加到主屏幕」。
- 装好之后是全屏打开、有自己的图标，不显示浏览器地址栏。

## 功能

| 页面 | 能做什么 |
| --- | --- |
| 首页 | 本月支出/预算进度、收入、结余，攒钱目标进度，最近记录 |
| 记账 | 按月翻查流水（不能翻到未来月份），按全部/支出/收入筛选；点任意一条可改金额、改日期、删除 |
| 统计 | 本月支出分类占比、近 6 个月支出柱状图、与前 5 个月平均对比、日均支出 |
| 目标 | 新建攒钱目标（名字、图标、目标金额、截止日期），存入 / 取出，显示还差多少、还剩几天 |
| 我的 | 月度预算、导出备份（JSON 文件）、导入备份、深色模式、添加到主屏幕、清空数据 |

记一笔：右下角 ＋ 或记账页右上角 ＋。金额支持小数，日期可改（补记前几天的账）。
按键盘回车也能直接保存。

## 数据与备份

- 数据存在**当前浏览器 + 当前网址**的 localStorage 里，key 是 `qingqian.v3`。
- 换浏览器、换网址、清理浏览器数据 → 数据不会跟过去，**独立**。
- 「我的 → 导出备份」会下载一个 `qingqian-backup-YYYY-MM-DD.json`，建议每月导一次。
- 「我的 → 导入备份」选这个 json 会**覆盖**当前数据（有二次确认）。
- 换新手机：旧手机导出 → 把 json 传到新手机 → 新手机打开同一个网址 → 导入。

## 改一改

- **配色**：`index.html` 顶部 `:root{--teal:...}` 一组 CSS 变量，全局跟着变。
- **分类**：搜 `var CATS=`，支出/收入的分类和 emoji 都在这里，改完保存即可。
- **预算提醒文案**：搜 `还没设预算`。

## 已知边界

- 只支持单币种（人民币）、单人使用，没有账号和云同步。
- 分类是固定的（不可自定义增减），够日常记账用。
- 未来月份不可查看（防止误记），历史月份可无限往前翻。

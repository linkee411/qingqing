# 青钱 · 记账（PWA）

一个只给你自己用的记账 App。手机浏览器打开、「添加到主屏幕」，用起来和装了个 App 一样。
数据全部存在你自己的设备上（localStorage），不上传任何服务器。

## 目录

```
qingqian-pwa/
├── index.html            整个 App（HTML + CSS + JS 全在一个文件里，无外部依赖）
├── manifest.webmanifest  应用信息：名字、图标、独立窗口打开
├── sw.js                 Service Worker：断网也能打开，导航请求走 network-first
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png
└── apple-touch-icon.png
```

## 怎么打开

**方式一：直接双击 `index.html`**（最简单，先用起来）
浏览器直接打开就能记账，数据存在本机。缺点：`file://` 下浏览器不允许注册 Service Worker，
所以不能「添加到主屏幕」，也不能离线。

**方式二：放到一个网址上（推荐，才能装到桌面）**

三种都免费、都不用命令行：

1. **Netlify Drop** —— 打开 https://app.netlify.com/drop ，把整个 `qingqian-pwa` 文件夹拖进去，
   几秒后给你一个 `https://xxx.netlify.app` 网址。手机上打开这个网址即可安装。
2. **GitHub Pages** —— 新建仓库，把文件夹里的文件传上去，Settings → Pages 选 main 分支，
   得到 `https://用户名.github.io/仓库名/`。
3. **Cloudflare Pages** —— 注册后 Upload assets，拖文件夹，得到 `https://xxx.pages.dev`。

要「添加到主屏幕」，网址必须是 **https**（上面三种自带）或 `localhost`。

**本机临时预览**（需要命令行）：

```bash
cd qingqian-pwa
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 添加到主屏幕

- **iPhone / iPad**：Safari 打开网址 → 分享按钮 → 「添加到主屏幕」。
- **Android**：Chrome 打开网址 → 右上角 ⋮ → 「安装应用」/「添加到主屏幕」。
- 装好之后是全屏打开、有自己的图标，不显示浏览器地址栏。

## 功能

| 页面 | 能做什么 |
| --- | --- |
| 首页 | 本月支出/预算进度、收入、结余；**超预算红色横幅**、**分类超支横幅**；**该记了**（周期账单到期提醒）；攒钱目标进度；最近记录 |
| 记账 | 按月翻查流水（不能翻到未来月份）；**搜索备注/分类/金额**（搜索时跨全部月份）；**筛选**（类型 + 分类 + 账户，可叠加）；类型支持**转账**；点任意一条可改金额、改日期、改账户、删除 |
| 统计 | **按月 / 按年 / 自定义区间**三种看法；支出 / 收入 / 收入−支出 三格自动算；支出分类占比（点分类可**下钻看子分类**）；**分类预算进度**（超了变红）；**按账户占比**；近 6 个月支出柱状图；有支出的天数、日均、笔数；与前 5 个月平均对比；**月度报告**（最大三笔、主要花在、一句话总结） |
| 目标 | 新建攒钱目标（名字、图标、目标金额、截止日期），存入 / 取出，显示还差多少、还剩几天；**快到期/已过期的目标卡片变红并打标**，首页顶部也会提醒（可对单个目标关掉提醒）；**存满了自动变绿、打「已达成」标、不再显示天数也不再提醒**，同时撒一把彩纸庆祝；目标页底部有**成就徽章墙**（存满 1 / 3 / 5 / 10 个逐级解锁） |
| 我的 | **账户管理**（每个账户填「记账前余额」，余额随记账自动加减）、**账户转账**（不算收支）、**总预算 + 分类预算 + 预算结转**、**币种与汇率**（记外币自动折算）、**记账提醒**、**常记模板**、**周期账单（支出 / 收入都行）**、**分类管理**、**导入微信/支付宝账单（CSV 或 xlsx，认不出可手动指定列）**、导出备份（JSON）、**导出 CSV**、导入备份、深色模式、添加到主屏幕、清空数据 |

记一笔：首页或记账页右上角 ＋。金额支持小数，日期可改（补记前几天的账），可以选账户（微信/支付宝/银行卡/现金，也可以不选）、
选子分类（交通→地铁/打车/加油……子分类可以在「我的 → 分类管理」以外的地方边记边加）、选币种（要先去「我的 → 币种与汇率」填汇率）。
顶部会列出**常记模板**，点一下就填好金额和备注。

**预算结转**：打开后本月可用 = 本月预算 + (上月预算 − 上月支出)，只结一层，负的不结。
**记账提醒**：设一个时间，到点当天还没记账时首页会出现提醒条；允许系统通知的话还会弹一条（只在 App 开着时生效，没有服务器做后台推送）。
**周期账单**：可以建支出也可以建收入（比如每月 5 号发工资），到日子在首页「该记了」里点一下确认。
按键盘回车也能直接保存。

**删错了 6 秒内点提示里的「撤销」就能找回**，不用再确认弹窗。

**目标提醒**：目标日期留空表示「无期限」。填了日期后，剩 30 天内在卡片上变成橙色、剩 7 天内变红色并打「快到期」标、
过期后打「已过期」标并在首页顶部弹一条提醒。不想被提醒就在编辑目标里把「到期提醒」关掉，单个目标单独生效。
存够了（已存 ≥ 目标）卡片会变成绿色、打「已达成」标，天数不显示，也不再进提醒。

**周期账单**：在「我的 → 周期账单」加一项（名称、金额、每月几号、分类），到日子首页会出一条「该记了」，
点「记一笔」自动填好金额和分类，点「本月不记」这个月不再提醒。

**自定义分类**：在「我的 → 分类管理」增删，支出和收入分开管理。删掉的分类只影响以后的选择，老记录保持原样。
按键盘回车也能直接保存。

**账户与余额**：在「我的 → 账户管理」里给每个账户填「记账前余额」（开始用青钱那天这个账户里有多少钱），
之后每记一笔带账户的支出/收入，余额自动加减；顶部显示所有账户的合计。账户可以改名删掉（有用过的账户不给删）。

**账户转账**：「我的 → 账户转账」，选从哪个账户到哪个账户、填金额。转账**不算支出也不算收入**，
只让两个账户的余额一减一加，首页和统计的收支不会被影响。记账页可以单独筛出「转账」。

**分类预算**：「我的 → 预算」里除了总预算，还能给每个分类单独设额度（留空=不限）。
在统计页能看到每类花了多少、用了百分之几；超了变红。首页顶部会弹「「餐饮」超了 ¥X」，点一下跳到统计。

**导入微信/支付宝账单**：在「我的 → 导入微信/支付宝账单」，导入微信或支付宝导出的账单文件（**`.csv` 和 `.xlsx` 都支持**，Excel 会直接在浏览器里解开，不需要先转 CSV）。

两家都不是「点一下就下载」，而是**申请后发到你邮箱**，附件是**加密压缩包**，解压码单独推送：

- 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → **用于个人对账** → 选时间范围 → 填邮箱 → 输支付密码。
  邮件里收到 `微信支付账单.csv.zip`，解压码由「微信支付」公众号发消息给你（6 位）。
  解压后得到 `.csv`（或 `.xlsx`，微信近版本给的是 Excel），**把解压出来的文件选进青钱**。
- 支付宝：我的 → 账单 → 常见问题 → 开具交易流水 → 选「用于个人对账」→ 填邮箱。
  同样收到压缩包，解压后是 GBK 编码的 `.csv`（青钱会自动按 GBK 读，不用另存 UTF-8）。

要点：**先把压缩包解压，选里面的表格文件**；直接选 .zip 青钱会提示「这是压缩包，请先解压」。

补充：表头认不出来时青钱会**按内容自动认列**（找日期列、金额列、收/支列），所以支付宝/微信改版换了列名也能导。
万一还是认不出，会弹一个「没认出这张表」，里面显示文件前 4 行 —— 把那张截图发我，我按你的表改。

补充：微信「下载账单 → 用作证明材料」给的是 **PDF**，那份是带公章的凭证，不是流水表，青钱不能导入；
只有「**用于个人对账**」给的 `.csv` / `.xlsx` 才能导。
邮件里的下载链接一般只有 7 天有效期，收到就存下来。时间范围微信最长 3 个月、支付宝可选更长，按页面提示来。

程序会自动识别表头、按「交易分类/交易对方/商品」猜分类、按「支付方式」猜账户（零钱→微信、花呗/余额宝→支付宝、银行→银行卡），
标记「不计收支」的行会跳过，**退款/交易关闭/失败的支出行会跳过**（钱没真花出去，微信里对应的「退款」收入行照常导入），
千分位金额（¥1,299.00）能正确识别，已经记过的同一笔会自动去重。导入前会先给你看前几笔确认。

## 数据与备份

- 数据存在**当前浏览器 + 当前网址**的 localStorage 里，key 是 `qingqian.v3`。
- 换浏览器、换网址、清理浏览器数据 → 数据不会跟过去，**独立**。
- 「我的 → 导出备份」会下载一个 `青钱备份-YYYYMMDD.json`（含流水、分类、账户、周期账单、目标），建议每月导一次。
- 「我的 → 导出 CSV」导出 `青钱账单-YYYYMMDD.csv`，Excel / WPS / Numbers 都能直接打开，适合做表或转给别人。
- 「我的 → 导入备份」选这个 json 会**覆盖**当前数据（有二次确认）。
- 换新手机：旧手机导出 → 把 json 传到新手机 → 新手机打开同一个网址 → 导入。

## 改一改

- **配色**：`index.html` 顶部 `:root{--teal:...}` 一组 CSS 变量，全局跟着变。
- **默认分类**：搜 `DEFAULT_CATS=`（改了只影响新用户；已有数据请在「分类管理」里改）。
- **默认账户**：搜 `DEFAULT_ACCS=`。
- **预算提醒文案**：搜 `还没设预算`。

## 已知边界

- 只支持单币种（人民币）、单人使用，没有账号和云同步。
- 周期账单只支持「每月固定金额」，到期需要你点一下确认，不会自动记账。
- 未来月份不可查看（防止误记），历史月份可无限往前翻。
- 搜索只匹配备注、分类、账户、金额和日期，不含标点模糊匹配。
